# 风格 04: 手绘涂鸦 / 视觉笔记 (Sketchnote / Doodle)

## 1. 风格概述与特征
- **风格定义**：模拟白板笔或针管笔在手账/白板上的手绘视觉笔记（Visual Note-taking），通过有机线条与涂鸦符号表达思考过程。
- **视觉标签**：手写白板感、轻松、生动、即兴思考感。
- **色彩体系**：纸白/米黄白板底（#FFFDF7） + 黑色手绘墨线（#222222） + 荧光黄/天蓝色马克笔高亮笔触。
- **视觉组件**：手绘不规则方框、双层手绘箭头、手绘灯泡/大脑/齿轮/火柴人、便签贴纸、手绘虚线圈注。

---

## 2. 版式设计与布局思路 (宽屏 vs 竖屏)

### 📱 竖屏布局 (9:16 移动端优先)
- **设计思路**：**垂直下行手绘探险流 / 便签纵向瀑布**。
- **视觉动线**：
  - **顶部**：手绘云朵主标题与核心引言。
  - **中部**：自上而下的手绘路线图（1 数据收集 -> 2 模型分析 -> 3 智能决策 -> 4 结果输出），通过手绘虚线和波浪箭头纵向串联。
  - **底部**：便签纸总结模块（“核心关键：数据 -> 算法 -> 洞察 -> 价值”）与手绘循环闭环。

### 🖥️ 宽屏布局 (16:9 桌面/PPT演示优先)
- **设计思路**：**放射状白板工作台 / 横向多列脑图笔记**。
- **视觉动线**：
  - **中心/左侧**：中心手绘大脑/核心议题大泡泡。
  - **向右发散**：分出 3~4 条手绘粗树枝，分别延伸出各个子主题的便签卡片、手绘插图与要点打勾清单。
  - **四周空白处**：点缀趣味灵感火花（Idea Bulbs）、图钉与团队行动倡议。

---

## 3. 适用场景与内容类型
- 读书笔记总结、会议纪要复盘、敏捷团队头脑风暴、个人成长方法论、创新策略构思。
