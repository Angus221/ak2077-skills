# 风格 13: 建筑剖面 / 微缩世界 (Cutaway Diorama)

## 1. 风格概述与特征
- **风格定义**：采用多层建筑/立体空间剖切面（Cutaway），将复杂的组织架构、业务单元或多阶段协作具象化为一栋“大楼”内不同房间中的微缩人群与交互场景。
- **视觉标签**：剖面空间、场景丰富、故事性强、身临其境。
- **色彩体系**：写实建筑混凝土/木质暖色调 + 室内温润暖光 + 左侧整洁标签指示色块。
- **视觉组件**：多层楼宇剖切面（数据中心 -> 研发实验室 -> 模型训练室 -> 控制中心 -> 展示厅） + 微缩人物角色在不同场景内互动。

---

## 2. 版式设计与布局思路 (宽屏 vs 竖屏)

### 📱 竖屏布局 (9:16 移动端优先)
- **设计思路**：**垂直高层建筑切面 (High-Rise Cutaway)**。
- **视觉动线**：垂直贯通的 5 层楼宇剖面自上而下展开，左侧引出各楼层职能胶囊标签（数据中心、研发中心、训练机房、指挥中心、展示厅），底部承接跨楼层协同说明。

### 🖥️ 宽屏布局 (16:9 桌面/PPT演示优先)
- **设计思路**：**横向智慧园区微缩切面 (Campus Complex Cutaway)**。
- **视觉动线**：横向铺开的 3 栋相连建筑切面（研发楼 / 算力楼 / 运营总部），中间带有空中连廊与数据光束连接，呈现出宏大的企业级空间生态协同。

---

## 3. 适用场景与内容类型
- 企业组织架构与跨部门协作流、研发全链路生活场景、智慧建筑运营全景、创新实验室探秘。
