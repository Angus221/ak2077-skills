# 风格 03: 3D 粘土拟物 (Claymorphism / Soft 3D)

## 1. 风格定位与特征
- **风格定义**：采用类似彩泥/黏土（Clay）的圆润软糯质感，微胖的圆角立体造型与柔和漫反射环境光，营造温暖、友好、亲切的视觉体验。
- **视觉标签**：圆润软质感、亲和、适合科普、童趣与高级感兼备。
- **色彩体系**：马卡龙莫兰迪柔和色系（浅青、鹅黄、薰衣草紫、珊瑚粉、薄荷绿） + 暖白底。
- **视觉组件**：软体管道连接件、圆滚滚的 3D 机器人/小图标、粘土质感卡片底座、泡泡浮雕徽章。

---

## 2. 版式设计与布局思路 (宽屏 vs 竖屏)

### 📱 竖屏布局 (9:16 移动端优先)
- **设计思路**：**垂直蛇形弯管串联 / 软糯卡片梯队**。
- **视觉动线**：
  - **顶部**：3D 粘土主标题徽章。
  - **中部**：自上而下的 S 型或垂直 3D 粘土导管，串联 4~5 块软糯圆角卡片。
  - **细节**：卡片内嵌精炼文案与 2D 微图标，兼顾趣味与移动端信息承载力。

### 🖥️ 宽屏布局 (16:9 桌面/PPT演示优先)
- **设计思路**：**横向 3D 粘土流水线 / 环形协同工坊**。
- **视觉动线**：
  - **横向主轴**：自左向右排布的 4~5 组 3D 粘土工坊/处理台，粗管道横向贯穿。
  - **上下分布**：上方挂载输入要素与参数小气泡，下方承接输出物与效果指标。
  - **全景感**：整体如同一条可爱的黏土自动化生产流水线。
