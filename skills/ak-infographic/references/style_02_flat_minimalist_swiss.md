# 风格 02: 扁平极简 / 瑞士国际主义 (Flat Minimalist / Swiss Style)

## 1. 风格定位与特征
- **风格定义**：源自经典瑞士国际主义平面设计（Swiss Style），强调绝对的秩序感、严谨网格与纯粹的几何美学。
- **视觉标签**：几何构成、严谨网格、信息传达高效、极简克制。
- **色彩体系**：大面积纯白/浅灰底（#FAFAFA） + 瑞士红（#E11D48）/ 经典原色（红黄蓝绿纯色几何块） + 墨黑正文字（#111827）。
- **视觉组件**：纯几何图形（圆形、方形、三角形）、扁平矢量图标、带编号数字徽章、标准间距虚实线框。

---

## 2. 版式设计与布局思路 (宽屏 vs 竖屏)

### 📱 竖屏布局 (9:16 移动端优先)
- **设计思路**：**单栏/双栏级联网格卡片流**。
- **视觉动线**：
  - **顶部**：粗黑无衬线大标题（Helvetica / Inter） + 核心总论摘要。
  - **中部**：4~6 组自上而下垂直堆叠的模块化卡片（01, 02, 03...），通过垂直中轴基准线精准对齐。
  - **底部**：全景总结卡片与对比微图表，单手滚动浏览极为舒适。

### 🖥️ 宽屏布局 (16:9 桌面/PPT演示优先)
- **设计思路**：**12 栏经典横向瑞士网格矩阵**。
- **视觉动线**：
  - **左侧 1/3**：醒目的大字号标题、版本/章节编号、大号引导段落与核心概念图。
  - **右侧 2/3**：2×2 或 3×2 模块化卡片阵列，各卡片之间内边距与间隙绝对严谨一致。
  - **底部贯穿栏**：核心指标对比与数据来源权威标注。
